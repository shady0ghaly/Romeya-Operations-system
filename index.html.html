تم تجهيز وتصدير ملف المهام لنظام Odoo بنجاح!

الملف مهيأ بصيغة CSV المتوافقة تماماً مع موديول المشاريع في أودو (project.task) بترميز UTF-8 مع BOM لدعم اللغة العربية 100%.

🚀 خطوات استيراد المهام في أودو (Import into Odoo):

  1. افتح نظام Odoo وانتقل إلى تطبيق Projects (المشاريع).
  2. ادخل على المشروع المطلوب أو اذهب إلى تبويب Tasks (المهام).
  3. في أعلى الصفحة بجانب شريط البحث، اضغط على زر ⚙️ Favorites (المفضلة) ⬅️ ثم اختر Import records (استيراد سجلات).
  4. اضغط على Upload File وارفع ملف الـ CSV الذي تم تنزيله الآن على جهازك.
  5. سيتعرف Odoo تلقائياً على كافة الأعمدة: [اسم المهمة: Name]، [المشروع: Project]، [المسؤول: Assigned to]، [الاستحقاق: Deadline]، [الوصف: Description]، [الوسوم: Tags].
  6. اضغط على زر Test للتحقق، ثم اضغط Import وستظهر كافة المهام مجدولة ومسندة لموظفيك فوراً!
